## Rendering architecture (the important part)

E1001 = **GRAY4** panel (4 gray levels), driven by Seeed_GFX/UC8179. Two text paths in `TextRenderer.cpp`:

1. **OpenFontRender (OFR)** — vector TrueType, any px, 14 families (`kFonts[]`, idx: DejaVu=1, **Lexend=4**, Open Sans=9). Pixel hooks (`ofrPaint`) map glyph coverage to the gray ramp:
   - **Smooth** (`g_aa=true`): anti-aliased → stroke edges land on lighter `GRAY_1/2` → reads grey.
   - **Crisp** (`g_aa=false`): threshold → every covered pixel = solid `g_ink` (`GRAY_0`) = **hard black**.
2. **Baked GFXfont bitmaps** (`OpenSansGFX.h`, generated by `fonts/gen_gfx.py` via freetype-py MONO) — 1-bit, pixel-grid-fit, solid `GRAY_0`. Rendered through Seeed_GFX `drawChar` (the `setFreeFont` path).

Key facts learned this session (don't re-derive):
- **`GRAY_0` IS true black** on this panel (the baked font names prove it). Text looks grey ONLY because of anti-aliasing (intermediate levels), NOT a weak black.
- The "dark→light at end of refresh" is the GRAY4 waveform: pixels overdrive toward black, then **intermediate (AA) grays settle to their lighter target**; `GRAY_0` pixels stay black. (`UC8179_Defines.h:159 LUT_KK_GRAY` vs `:95 LUT_KK`.)
- LUT/VCOM tuning to deepen black is **blocked** — the panel runs its internal **OTP** waveform (`TFT_eSPI.cpp:1654 _uc8179_use_otp_lut`); the v1.11.2 host VCOM edit had zero visible effect.
- So: hard black = render **crisp** (no AA) or **baked**. No BW-mode needed.

Renderer entry points / knobs (all runtime, global state):
- `setFontIndex(i)`, `setSmoothing(g_aa)`, `setSmallCrisp(g_smallCrisp)`, `setWeight(g_weight)`, `setSharpness(g_sharp)`.
- `drawTextFace()` → dashboard. When `g_smallCrisp` and face is small → `faceGfx()` (baked **Lexend** R10/R13/B13/B17); else OFR.
- `drawTextPx()` / `drawTextPxBaked()` / `textWidthPx()` / `fontName()` — arbitrary-px helpers for the playground. `bakedOpenSans(px,bold)` = the **Open Sans** full ladder (6–34), used by the playground + all-fonts name labels.

## Settings UI

- **System tab** has an **Advanced** toggle (checkbox, client-side, `localStorage` key `um_adv`, default OFF, no Save). CSS `body.adv` gates `.adv-only` / `.simple-only`.
  - Advanced OFF hides: Battery full (mV), Smooth Text, Crisp small text, Text Sharpness, Text Weight, the Font Testing tab. Shows **Hard Black (Crisp, no antialias)**.
  - **Hard Black ⇄ Smooth Text are the same `ui_aa` bool** (opposite polarity), kept in sync by `syncHB()`/`syncAA()`; `collect()` reads `ui_aa`. Hard Black on = `ui_aa=false`.
- **Font Testing tab** drives the device playground via `POST /api/fonttest?on=&font=&dark=&all=&crisp=&size_idx=` → callback `onFontTest(on,font,dark,all,crisp,sizeIdx)` in `UsageApp`. `dark/all/crisp = -1` means "unchanged" (so live size steps keep saved dark/view). Runtime-only — **off after reboot**.
  - Apply model: **size/font/on = live**; **Dark + All Font View + Crisp = on Save** (the Save Settings button calls `ftSendSave()`).
